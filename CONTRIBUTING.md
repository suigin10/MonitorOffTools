# Contributing

Bug reports and small improvement proposals are welcome through GitHub Issues.

When reporting a problem, include the following information where possible:

- Windows 11 version
- GPU and driver version
- Monitor connection type, such as DisplayPort or HDMI
- Number of connected monitors
- Whether the issue occurs with manual monitor-off, idle auto-off, or wake-prevention monitoring
- Steps that reproduce the issue

Pull requests should remain focused and preserve the lightweight, dependency-free design of the application.
